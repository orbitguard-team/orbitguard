# OG-05. Метрики и экспорт результата

`build_metrics(result, compute_time_s=...)` возвращает словарь для интерфейса.
Длительность измеряет вызывающий код вокруг расчёта и передаёт в секундах.
`before` и `after` содержат `d_min_m`, `t_min_s`, `rel_speed_mps` и
`violated`, если соответствующий расчёт выполнен. Времена отсчитываются
от UTC-эпохи сценария.

Поля `dv_eci_mps`, `dv_mps` и `impulse_t_s` описывают выбранный импульс.
В состоянии `already_safe` вектор и норма нулевые, время импульса равно
`null`. При отсутствии решения или ошибке неизвестные метрики равны
`null`. Топливо в этой версии не рассчитывается и в отчёт не включается.

`export_result_json(scenario, result, candidates=..., compute_time_s=...)`
возвращает JSON-строку. Документ содержит:

- `schema_version` — версия формата отчёта, сейчас 1.
- `units` — единицы СИ для положения, скорости, времени, массы и площади.
- `scenario` — входной сценарий v1 согласно контракту, включая эпоху,
  систему отсчёта, начальные состояния, силы, допуски и ограничения.
- `candidates` — переданный на вход поиску полный список импульсов в
  исходном порядке. Каждый содержит `t_s` и `dv_eci_mps`.
- `metrics` — результат расчёта, его статус и длительность.
- `message` — диагностическое сообщение расчёта, если оно было задано.

Для повторного запуска извлеките `scenario` как входной JSON и
восстановите `candidates` как упорядоченную последовательность `Impulse`.
Не заменяйте кандидатов журналом расчёта: поиск может закончиться до их
оценки. Длительность предыдущего расчёта хранится для сравнения.
