# OG-05. Метрики и экспорт результата

Файловый API принимает `export_json(scenario, result, path)`. Для интерфейса
`summarize(result)` возвращает словарь, а `export_result_json(scenario, result)`
возвращает JSON-строку для скачивания. Все три функции принимают
`compute_time_s`, если вызывающий код измерил время расчёта. Интерфейс может
передать исходный `scenario` в `summarize` или `build_metrics`, чтобы
показать порог, запас и настройки модели сил даже при ошибке прогноза.
`build_metrics(result, compute_time_s=...)` остаётся доступным.

В интерфейсе OG-08 используйте
```python
metrics = summarize(result, scenario=scenario, compute_time_s=elapsed_s)
```

С текущими моделями без `scenario` настройки сил и запас могут быть
неизвестны, тогда `forces`, `distance_margin_m` и `accepted` равны `null`.

В `before` и `after` есть `d_min_m`, `t_min_s` и `rel_speed_mps`.
Моменты отсчитываются от UTC-эпохи сценария. `violated` означает
`d_min_m < safe_distance_m`. `accepted` проверяет порог с запасом:
`d_min_m ≥ safe_distance_m + distance_margin_m`. Если запас неизвестен,
`accepted` равен `null`. `d_min_gain_m` — разница минимумов после и до.

Поля `dv_eci_mps`, `dv_mps` и `impulse_t_s` описывают выбранный импульс.
В состоянии `already_safe` вектор и норма нулевые, время импульса равно
`null`. При отсутствии решения или ошибке недоступные метрики равны
`null`. Топливо не рассчитывается и в отчёт не включается.

## JSON v1

- `schema_version` — версия формата отчёта, сейчас 1.
- `units` — единицы СИ для положения, скорости, времени, массы и площади.
- `scenario` — входной сценарий v1 с эпохой, системой отсчёта,
  начальными состояниями, силами, допусками и ограничениями.
- `candidates` — входные импульсы в исходном порядке, с `t_s` и
  `dv_eci_mps`. После полного перебора их можно восстановить из журнала.
  Если переданы оба списка, их длина, порядок и значения должны совпасть.
- `candidate_results` — журнал с импульсом, `admissible`, причиной и
  метриками `after`, если траектория пересчитана.
- `metrics` и `message` — метрики, статус и диагностическое сообщение.
- `software` — версии OrbitGuard, Python, NumPy и SciPy. Передайте
  `git_commit`, если известна ревизия расчёта. Неизвестные версии
  сохраняются как `null`. Метка времени генерации не добавляется.

Для повторного запуска извлеките `scenario` и восстановите
`candidates` как упорядоченную последовательность `Impulse`. Когда
поиск завершился до перебора (`already_safe` или `propagation_failed`),
передайте исходный набор явно. Если в результате есть частичный журнал,
он должен совпадать с соответствующим началом входного набора. Без набора
отчёт доступен, но `candidates: null` означает, что полный вход
восстановить нельзя.
