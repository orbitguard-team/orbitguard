## OG-01 · Контракт данных

**Цель:** договориться о форматах до начала кода, чтобы все работали параллельно.

- [ ] Единицы СИ, инерциальная система координат (ECI), время — секунды от даты начала (UTC).
- [ ] Описаны структуры: сценарий, траектория, результат сближения, результат манёвра, статусы ошибок.
- [ ] Описаны функции `propagate`, `find_closest_approach`, `search_maneuver` и общая функция силы `accel(t, r, v, params)`.
- [ ] Описаны параметры объектов (масса, площадь, коэффициент сопротивления) и включение сил.
- [ ] Выбраны версия Python, зависимости, команды установки и запуска тестов.
- [ ] Зафиксированы численные допуски.
- [ ] Есть маленький пример данных для интерфейса и тестов.

## OG-02 · Прогноз движения

**Цель:** по начальному положению и скорости рассчитать траекторию методом RK45.

- [ ] Ускорение — сумма включённых сил; новые силы подключаются без правки `propagate`.
- [ ] Положение можно получить в любой момент времени (нужно для точного поиска сближения).
- [ ] Ошибки расчёта и некорректные данные возвращаются явно.
- [ ] Тесты: период круговой орбиты, сохранение энергии, сходимость при повышении точности.

## OG-03 · Поиск сближения

**Цель:** найти момент и расстояние минимального сближения двух объектов.

- [ ] Возвращает время, расстояние и признак «ближе безопасной дистанции».
- [ ] Минимум уточняется между точками сетки, учитываются края интервала.
- [ ] Тесты: несколько минимумов, минимум на краю, сравнение с аналитическим примером.

## OG-04 · Подбор манёвра

**Цель:** найти безопасный импульс с минимальным Δv.

- [ ] Перебираются момент, направление и величина импульса в заданных пределах.
- [ ] После импульса орбита пересчитывается; безопасность проверяется на всём интервале.
- [ ] Выбирается минимальное Δv среди безопасных вариантов.
- [ ] Статусы: уже безопасно / манёвр найден / манёвр не найден.
- [ ] Тесты: ограничение Δv, случай без решения.

## OG-05 · Метрики и экспорт

**Цель:** сравнить «до» и «после» и сохранить результат.

- [ ] Дистанция и время сближения до/после, вектор и величина Δv, момент импульса, время расчёта.
- [ ] Экспорт содержит все входные данные — расчёт можно повторить.
- [ ] Расход топлива — только если заданы масса и удельный импульс двигателя.

## OG-06 · Сценарии

**Цель:** готовые воспроизводимые примеры для демо и тестов.

- [ ] Безопасный (манёвр не нужен), опасный (манёвр найден), без решения в заданных пределах.
- [ ] МКС-подобная орбита (≈420 км, наклон 51.6°).
- [ ] Сценарий, где атмосфера по-разному тормозит объекты и меняет сближение.
- [ ] У каждого: дата, силы, параметры объектов, ожидаемый статус; синтетические данные помечены.

## OG-07 · Черновик интерфейса

**Цель:** страница Streamlit на тестовых данных.

- [ ] Выбор сценария, безопасная дистанция, интервал, ограничения, переключатели сил, кнопка запуска.
- [ ] 3D-график траекторий с точками сближения и импульса.
- [ ] График расстояния во времени с линией безопасной дистанции.
- [ ] Видны ошибки ввода и ход расчёта; тестовые данные помечены.

## OG-08 · Интеграция интерфейса

**Цель:** интерфейс работает на реальном расчёте.

- [ ] Все сценарии запускаются из интерфейса; все числа и графики из одного расчёта.
- [ ] После изменения настроек не остаётся старого результата.
- [ ] «Манёвр не найден» показан честно, без ложной отметки «безопасно».
- [ ] Запуск по команде из README.

## OG-09 · Тесты и CI

**Цель:** тесты запускаются автоматически на каждый PR.

- [ ] GitHub Actions ставит зависимости и запускает pytest.
- [ ] Не нужны личные токены и интернет для данных.
- [ ] Пустой набор тестов не даёт зелёный результат.

## OG-10 · Проверка результатов

**Цель:** подтвердить, что числа для защиты верны и воспроизводятся.

- [ ] Записаны метрики всех сценариев и commit, на котором они получены.
- [ ] После манёвра дистанция безопасна на всём интервале.
- [ ] Измерен вклад каждой силы и влияние плотности атмосферы.
- [ ] Другой участник запустил проект с нуля по README.

## OG-11 · Обоснование проекта

**Цель:** материалы для критериев «реализуемость», «БРИКС», «бизнес».

- [ ] Уровень готовности технологии (УГТ): текущий и целевой, с объяснением.
- [ ] Риски, план развития, оценка затрат.
- [ ] Конкретные страны БРИКС, пользователи и форма сотрудничества.
- [ ] Кто платит и за что, сравнение с конкурентами.
- [ ] Факты — со ссылками, гипотезы помечены.

## OG-12 · Защита

**Цель:** выступление на 3 минуты и резервное демо.

- [ ] Слайды с числами из OG-10; вклад каждого участника виден.
- [ ] Текст выступления, репетиция не дольше 3 минут.
- [ ] Ответы на вопросы: физика, ограничения, УГТ, конкуренты, БРИКС.
- [ ] Резервная запись демо; проверка запуска на втором компьютере.

## OG-13 · Сила J2

**Цель:** учесть сплюснутость Земли. Формулы — [PHYSICS.md](PHYSICS.md).

- [ ] Ускорение по формуле J2.
- [ ] Тест: дрейф плоскости орбиты совпадает с аналитической формулой.
- [ ] Тест: сохраняются энергия и z-компонента момента импульса.

## OG-14 · Атмосфера

**Цель:** учесть сопротивление воздуха. Формулы — [PHYSICS.md](PHYSICS.md).

- [ ] Модель плотности по высоте с указанным источником; множитель плотности для солнечной активности.
- [ ] Учтено вращение атмосферы вместе с Землёй.
- [ ] Без массы и площади объекта сила не считается, и это видно в результате.
- [ ] Тест: скорость снижения орбиты совпадает с аналитической оценкой.

## OG-15 · Луна и Солнце

**Цель:** учесть притяжение Луны и Солнца. Формулы — [PHYSICS.md](PHYSICS.md).

- [ ] Положения Луны и Солнца по упрощённым формулам из указанного источника.
- [ ] Тест: положения сверены с опубликованными значениями на нескольких датах.
- [ ] Тест: вклад силы измерен и соответствует оценке порядка величины.
