# Заготовки GitHub Issues

Путь B: Python + Streamlit. Это локальный backlog для согласования, не опубликованные issues.
OG-xx — устойчивые обозначения плана; реальные #N появятся после публикации.
Каждый блок ниже — отдельный issue. Обязательная общая приёмка: PR, проверки, одно независимое review.
Исполнителя и ревьюера команда выбирает сама и назначает в issue; ревьюер — не автор PR.

Зависимости: нет.
Файлы: docs/contracts.md, src/orbitguard/models.py, конфигурация Python-проекта.

- [ ] Описаны конфигурация сил (центральное поле, J2, атмосфера, Луна, Солнце), общая сигнатура

- [ ] Описаны структуры Scenario, Trajectory, ConjunctionResult, ManeuverResult и статусы ошибок.

- [ ] Выбраны версия Python, зависимости, команды установки/проверки.
- [ ] Зафиксированы физические ограничения, численные допуски и критерий допустимости.
- [ ] Есть маленький пример данных для независимой разработки UI и тестов.

Не входит: полноценная реализация алгоритмов.
