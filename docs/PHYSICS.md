# Физическая модель OrbitGuard

## Уравнение движения

Состояние объекта — положение **r** и скорость **v**. Система координат инерциальная (ECI), единицы СИ.

```
dr/dt = v
dv/dt = a_Земля + a_J2 + a_атмосфера + a_Луна + a_Солнце
```

Решается численно методом RK45 (`scipy.integrate.solve_ivp`). Каждая сила — отдельная функция,
её можно включить или выключить в сценарии.

## Силы

Оценки для низкой орбиты (~400 км). Точные значения измеряются в OG-10.

| Сила | Ускорение, м/с² | Что даёт | Задача |
|---|---|---|---|
| Притяжение Земли | ~8.7 | Движение по орбите | OG-02 |
| Сплюснутость Земли (J2) | ~10⁻² | Плоскость орбиты поворачивается (~5° в сутки для МКС) | OG-13 |
| Атмосфера | ~10⁻⁶–10⁻⁵ | Орбита снижается; объекты расходятся вдоль орбиты | OG-14 |
| Луна | ~10⁻⁶ | Малые возмущения | OG-15 |
| Солнце | ~10⁻⁷ | Малые возмущения | OG-15 |

## Формулы

| Сила | Формула | Обозначения |
|---|---|---|
| Земля | a = −μ·r / \|r\|³ | μ = 3.986004418·10¹⁴ м³/с² |
| J2 | a_x = k·x·(1 − 5z²/r²)<br>a_y = k·y·(1 − 5z²/r²)<br>a_z = k·z·(3 − 5z²/r²)<br>k = −1.5·J2·μ·R²/r⁵ | J2 ≈ 1.0826·10⁻³, R ≈ 6378 км |
| Атмосфера | a = −½·ρ(h)·B·\|v_rel\|·v_rel<br>v_rel = v − ω × r | B = Cd·A/m — «парусность» объекта<br>ρ(h) — плотность на высоте h<br>ω = 7.292115·10⁻⁵ рад/с — вращение Земли |
| Луна, Солнце | a = μ_b·[(r_b − r)/\|r_b − r\|³ − r_b/\|r_b\|³] | r_b — положение тела<br>μ_Луна = 4.9028·10¹² м³/с²<br>μ_Солнце = 1.32712440018·10²⁰ м³/с² |

## Допущения

| Сила | Допущение |
|---|---|
| J2 | Ось вращения Земли неподвижна (без прецессии и нутации) |
| Атмосфера | Плотность по таблице из Vallado, «Fundamentals of Astrodynamics and Applications»; солнечная активность — множитель плотности (по умолчанию 1) |
| Атмосфера | Высота над эллипсоидом, а не над сферой (иначе ошибка до 21 км у полюсов) |
| Атмосфера | Масса, площадь и Cd задаются в сценарии; без них сила не считается, и это видно в результате |
| Луна, Солнце | Положения по упрощённым формулам: Montenbruck, Gill, «Satellite Orbits», разд. 3.3.2 (точность — угловые минуты) |
| Луна, Солнце | Нужна дата начала сценария (UTC) |

**МКС** — не сила (её притяжение ничтожно), а пример защищаемого объекта: синтетическая орбита
≈420 км, наклон 51.6°. Реальные данные МКС (TLE) не используем — они рассчитаны в другой модели (SGP4).

## Проверки

| Сила | Тест | Ожидание |
|---|---|---|
| Земля | Период круговой орбиты | T = 2π·√(a³/μ) |
| Земля | Энергия и момент импульса | Не меняются |
| J2 | Дрейф плоскости орбиты за сутки | dΩ/dt = −1.5·n·J2·(R/p)²·cos i |
| J2 | Энергия и z-компонента момента | Не меняются |
| Атмосфера | Снижение круговой орбиты при постоянной плотности | da/dt = −ρ·B·√(μ·a) |
| Атмосфера | Объект движется вместе с атмосферой | Торможения нет |
| Луна, Солнце | Положения на нескольких датах | Совпадают с опубликованными (эталон в репозитории) |
| Луна, Солнце | Точка в центре Земли | Ускорение = 0 |
| Все | Повышение точности расчёта | Результат сходится |

## Что не учитываем

Гармоники гравитации выше J2, давление солнечного света, изменения атмосферы со временем,
неопределённость начальных данных. Поэтому минимальная дистанция — расчётная оценка,
а не вероятность столкновения.

Если сила не прошла проверки к интеграции, она остаётся выключенной и уходит в «развитие».
