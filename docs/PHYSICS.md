# Физическая модель OrbitGuard

План расширения модели движения: вместо чистой двухтельной задачи учитываются
сплюснутость Земли (J2), сопротивление атмосферы, притяжение Луны и Солнца.
Задачи: OG-13, OG-14, OG-15 (docs/BACKLOG.md). Точные константы, допуски и сигнатуры
окончательно фиксируются в OG-01 и docs/contracts.md.

## Уравнение движения

Состояние объекта — положение r и скорость v в инерциальной системе (ECI), единицы SI.

```
dr/dt = v
dv/dt = a_central + a_J2 + a_drag + a_Moon + a_Sun
```

Интегратор не меняется: RK45 (scipy.integrate.solve_ivp). Каждое слагаемое —
отдельная функция ускорения с общей сигнатурой `accel(t, r, v, params) -> ndarray(3)`;
propagate суммирует включённые слагаемые. Набор включённых сил — часть сценария
и сохраняется в результате, чтобы расчёт можно было повторить.

## Оценка вкладов (низкая орбита, высота ~400 км)

| Слагаемое | Порядок ускорения, м/с² | Главный эффект |
|---|---|---|
| Центральное поле Земли | ~8.7 | Кеплерова орбита |
| J2 | ~10⁻² | Поворот плоскости орбиты и линии апсид |
| Атмосфера | ~10⁻⁶–10⁻⁵ (сильно растёт ниже) | Снижение орбиты, расхождение объектов вдоль орбиты |
| Луна | ~10⁻⁶ | Малые периодические возмущения |
| Солнце | ~10⁻⁷ | Малые периодические возмущения |

Это оценки порядка величины. Фактический вклад каждой силы в сценариях измеряется
в OG-10 и записывается в docs/validation.md; на слайды идут только измеренные числа.

## 1. Центральное поле

a = −μ·r/|r|³, μ = 3.986004418·10¹⁴ м³/с².

## 2. Сплюснутость Земли (J2) — OG-13

Земля сжата у полюсов; избыточная масса у экватора даёт добавку к потенциалу
U_J2 = −(μ/r)·J2·(R/r)²·(3·sin²φ − 1)/2, где sin φ = z/r.

```
k   = −1.5·J2·μ·R²/r⁵
a_x = k·x·(1 − 5z²/r²)
a_y = k·y·(1 − 5z²/r²)
a_z = k·z·(3 − 5z²/r²)
```

J2 ≈ 1.0826·10⁻³, R ≈ 6378.137 км (пара значений берётся из одной модели гравитации, фиксируется в OG-01).
Ось z системы ECI совпадает с осью вращения Земли (прецессия и нутация не учитываются).

Ожидаемый эффект — вековой дрейф долготы восходящего узла:
dΩ/dt = −1.5·n·J2·(R/p)²·cos i, где n = √(μ/a³), p = a(1 − e²).
Для МКС-подобной орбиты это около −5° в сутки.

## 3. Сопротивление атмосферы — OG-14

```
a_drag = −½·ρ(h)·B·|v_rel|·v_rel,   B = Cd·A/m,   v_rel = v − ω_E × r
```

- ω_E = 7.292115·10⁻⁵ рад/с вокруг оси z: атмосфера вращается вместе с Землёй.
- ρ(h) — статическая кусочно-экспоненциальная модель плотности (таблица из Vallado,
  «Fundamentals of Astrodynamics and Applications»); источник таблицы указывается в коде.
- Высота h считается над эллипсоидом в приближении h ≈ |r| − R·(1 − f·sin²φ), f ≈ 1/298.257.
  Над сферой ошибка у полюсов до ~21 км, что меняет плотность в разы.
- Солнечная активность меняет плотность в разы. Вводится явный множитель плотности
  (по умолчанию 1), и чувствительность к нему проверяется в OG-10.
- Cd, площадь A и масса m задаются для каждого объекта в сценарии с пометкой «допущение»,
  если не взяты из источника. Без этих параметров сопротивление для объекта не считается,
  и результат явно сообщает об этом; подставлять скрытые значения по умолчанию нельзя.
- Изменение массы при манёвре в B не учитывается (импульс мгновенный, расход мал).

## 4. Луна и Солнце — OG-15

Приливное ускорение третьего тела (притяжение спутника минус притяжение Земли):

```
a_3 = μ_b·[ (r_b − r)/|r_b − r|³ − r_b/|r_b|³ ]
```

- μ_Moon = 4.9028·10¹² м³/с², μ_Sun = 1.32712440018·10²⁰ м³/с².
- Положения r_b(t) — упрощённые аналитические формулы низкой точности
  (Montenbruck, Gill, «Satellite Orbits», разд. 3.3.2): точность порядка угловых минут,
  этого достаточно, потому что сам эффект мал. Новые библиотеки не нужны.
- Перевод из эклиптических координат в экваториальные — поворот на наклон эклиптики ε ≈ 23.439°.
- Для этого эпоха сценария — абсолютная дата и время (UTC); аргумент эфемерид — TT ≈ UTC + 69.184 с.
- Потеря точности при вычитании близких величин для низких орбит допустима (теряется 4–5 значащих
  цифр из 16); при необходимости заменяется формулой Баттина.

## 5. МКС в сценариях

МКС не создаёт заметного ускорения для других объектов и как сила не моделируется.
Она используется как пример защищаемого объекта: синтетическая МКС-подобная орбита
(высота ~420 км, наклонение 51.64°, почти круговая). Реальные TLE не используются:
они согласованы с моделью SGP4, и смешивать их с нашей моделью некорректно.
Синтетический характер данных явно указывается в сценарии и на защите.

## Проверки

| Сила | Проверка | Ожидание |
|---|---|---|
| Центральная | Период круговой орбиты | 2π·√(a³/μ) |
| Центральная | Энергия и вектор момента импульса | Сохраняются в пределах допуска |
| J2 | Энергия с учётом U_J2 и z-компонента момента | Сохраняются (поле осесимметрично и не зависит от времени) |
| J2 | Средний дрейф узла за сутки | Совпадает с аналитической формулой dΩ/dt |
| Атмосфера | Энергия орбиты | Монотонно убывает |
| Атмосфера | Круговая орбита при постоянной плотности | da/dt ≈ −ρ·B·√(μ·a) |
| Атмосфера | Объект, движущийся вместе с атмосферой | a_drag = 0 |
| Луна/Солнце | Эфемериды на нескольких датах | Совпадают с опубликованными значениями (фикстура в репозитории, без сети в CI) |
| Луна/Солнце | Спутник в центре Земли | a_3 = 0 |
| Все | Переключатели сил | Сумма включённых слагаемых, выключенная сила не влияет |
| Все | Ужесточение допуска интегратора | Положение через горизонт сходится |
| Все | Вклад каждой силы | Расхождение траекторий с силой и без неё за горизонт записано в validation.md |

## Влияние на остальные модули

- Контракт (OG-01): абсолютная эпоха UTC, описание ECI, конфигурация сил,
  физические параметры объектов (масса, Cd, площадь), статус «сила отключена из-за нехватки данных».
- Поиск манёвра (OG-04): каждый кандидат пересчитывается дороже. Отбор кандидатов
  допускается на упрощённой модели, но итоговая проверка безопасности и Δv — всегда
  на выбранной полной модели, и это указывается в результате.
- Интерфейс (OG-07/08): переключатели сил, отображение включённых сил и допущений
  (параметры атмосферы, множитель плотности).
- Сценарии (OG-06): МКС-подобная орбита; сценарий, где разная парусность объектов меняет сближение.

## Что по-прежнему не учитывается

Гармоники гравитации выше J2, давление солнечного излучения, модель атмосферы с солнечной
активностью (NRLMSISE и т. п.), прецессия и нутация, точные эфемериды, неопределённость
начальных состояний. Поэтому минимальная дистанция остаётся детерминированной оценкой,
а не вероятностью столкновения, и результат не является основанием для управления реальным аппаратом.

Если к 25 ноября какая-то из сил не прошла проверки, она остаётся выключенной
и указывается в «развитии», а не выдаётся за реализованную.
