# OrbitGuard

Исследовательский симулятор безопасных орбитальных манёвров команды Chuykinteam.
Кейс: «Моделирование полета и расчет траекторий для космических миссий».

Интерфейс запускает двухтельный расчёт RK45, ищет сближение и проверяет
кандидаты импульсного манёвра на трёх синтетических сценариях.

Первый запуск (Python 3.11–3.13, в виртуальном окружении):

```sh
python -m pip install -e ".[dev]"
python -m pytest -q
python examples/contract_example.py
```

Пример проверяет только входные данные, не вычисляет траекторию или безопасность.

## Интерфейс

Из корня репозитория в том же виртуальном окружении:

```sh
python -m pip install -e ".[ui]"
python -m streamlit run app.py
```

Выберите [сценарий](docs/scenarios.md), проверьте настройки и нажмите
«Рассчитать». Интерфейс показывает минимум дистанции, время сближения,
траектории и сравнение до и после импульса, если он найден. JSON-отчёт
сохраняет исходные параметры и набор проверяемых импульсов.

Поиск использует до трёх равномерно распределённых моментов окна,
два направления вдоль орбиты и 20, 50 и 100% бюджета Δv. Расчёт
проверяет геометрический порог с запасом. Текущий режим учитывает
центральную гравитацию. Подробнее о [физической модели](docs/PHYSICS.md).
